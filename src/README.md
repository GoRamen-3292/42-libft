## Description

このプロジェクトでは、Cの標準ライブラリに含まれているものを含む、今後一般的によく使われるであろう関数を再実装する。

C言語は適切なライブラリがないと、扱うのが極めて難しくなってしまう。ここでは、そういったライブラリに用いられる関数を、自身で再実装してライブラリを制作することを通して理解し、また効果的に使用することができるようにする。
